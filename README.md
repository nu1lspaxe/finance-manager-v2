# Finance Manager (v2)

Different from [finance-manager](https://github.com/nu1lspaxe/finance-manager), the finance-manager-v2 is designed with microservice idea and combined the utilities with Kafka and gRPC.


## Services

### Users

- [POST] **CreateUser** `/v1/user`
- [GET] **GetUser** `/v1/users/{id}`
- [GET] **ListUsers** `/v1/users`
- [Patch] **UpdateUser** `/v1/users/{id}`
- [Delete] **DeleteUser** `/v1/users/{id}`
